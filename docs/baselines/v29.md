# V29 hybrid baseline

This is the completion baseline to preserve before developing the new teacher
and RGB distillation pipeline. The original ACT weights were not retrained.

## What passed

The [independent qualification report](v29-readiness.json) is copied unchanged
from `outputs/hybrid-readiness-v29/policy_readiness_rechecked.json` so that its
results and exact controller configuration are versioned with the source.
Absolute paths in the report identify the original local artifacts.

| Tested blue-robot task | Complete moves |
| --- | --- |
| Initial e2–e4 | 20/20 |
| Initial d2–d4 | 20/20 |
| g1–f3 in the tested open-game position | 20/20 |
| First capture e4×d5 after e2–e4, d7–d5 | 20/20 |

Each task used ten seeds repeated twice. All tested captured victims finished
upright. Two additional complete, upright capture episodes were exported as a
local LeRobot dataset: 1,793 frames at 30 Hz. Source trajectories were audited
in full; actual LeRobot read-back checked six sampled frames against the source
images, states, executed actions, indices and timestamps.

## Limits and motion quality

Ordinary moves use the retained v6 ACT/residual expert. Captures use a v24
learned residual plus the explicit v29 timing/transport supervisor. The capture
supervisor follows lift/transfer/lower waypoints, settles at endpoints, and
returns home before restarting ACT for the attacker. These interventions produce
pauses and inefficient travel. The result demonstrates completion reliability
within the tested scope, not the motion quality desired for imitation training.
No new RL improvement is claimed.

The user reviewed the recordings and identified these motion issues. Improve
trajectory quality before bulk collection: a student may imitate the teacher's
pauses and detours. The proposed next direction is a goal-conditioned simulation
teacher and an RGB student conditioned on desired board layout. That pipeline
is not implemented in this baseline.

Other moves, arbitrary board states, occupied capture areas, red-robot control,
special moves and real-hardware transfer have not been qualified by these trials.
